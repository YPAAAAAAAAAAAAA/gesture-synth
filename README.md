# gesture-synth

A clean-room, from-scratch re-implementation of the idea behind **[ekmand/gesture-synth](https://github.com/ekmand/gesture-synth)** by [@ekmand](https://github.com/ekmand). The original project had no open-source licence, so no code or assets were copied: only the concept (and its public description) was used as inspiration. All code and assets in this repository are original.
